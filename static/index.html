更新方式与数据边界

在线更新“更新 Cloudflare 岗位”仅读取该公司的技术岗位来源；其他来源由采集脚本更新后重新载入。

样本边界不同来源提供的字段不同，缺失信息保留为未知。

重复处理同来源、同岗位 ID 更新；人工下架状态保留。

关键操作记录

质量问题分布

按当前数据范围和筛选计算。一条岗位可有多个问题，问题数量之和可能大于岗位数。可选字段缺失不删除岗位；疑似重复不自动合并。

字段核验

打开岗位详情，对照原文确认学历与经验。管理员可核验公开来源；企业维护者可核验本企业岗位。提取建议需确认后才计入具体分类。

岗位 / 公司问题说明来源操作

疑似重复判断

相同公司、标题与地区的不同记录会进入候选，包括同来源的不同 ID。对照原文判断是否为同一招聘岗位；判断可撤销，来源记录始终保留，“同一岗位”不代表相同招聘人数。
